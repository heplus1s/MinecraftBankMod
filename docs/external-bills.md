# 银行公共汇票接口

同服的、已安装且受信任的 Fabric 服务端模组可使用
`dev.jdguo.bank.market.ExternalClearing`。接入方固定使用自己的模组 ID，
不要接受客户端提供的其他模组 ID、付款账户、报价金额或流水号。
费用定价、业务确认、找零和履约由接入方负责。接口用每模组唯一的 `<modid>_<UUID>`
流水号，网络重试保持原流水号。调用发生在游戏服务器线程上。

- `quoteBill(mod, player)`：读取主手登记汇票，核对票面和收款人，返回序列号、票面、币种；不动账。
- `receiveBill(mod, player, serial, face, ref)`：重新校验主手同票。银行核销全票、将全额划至该系统资金口径；账本提交后才消耗实体票。银行不计算业务扣款或找零。
- `issueInstrument(mod, player, "bill", amount, ref)`：公共系统不需要普通银行储蓄账户，但须先具备可用资金。银行在同一事务扣除属于该系统的已结算资金、登记汇票，余额不足不出票。模式 `cash` 也可用。
- `issueBillFromSavings(mod, owner, payee, amount, ref)`：个人储蓄路径。接入方必须在认证的在线账户本人明确确认币种、金额和收款人之后才调用。传入真实在线账户持有人对象，不得从未经认证的请求接受付款人 UUID。收款人可以离线，账本先登记记名票据，之后领取。暂不提供独立部门账户开户或授权管理。
- `claimInstrument(mod, player)`：只交付同一系统为本人登记的待领取票据；背包满时保留，库存回执用来恢复已交付但尚未完成记账的操作。
- `recorded(mod, ref)` 可重查已入账流水；公服找零或退还个人储蓄可用既有 `credit`，由接入方决定和发起。

这不是 HTTP API，也不是隔离不可信服务器插件的沙箱。银行沿用现有票据和资金账目，无需迁移已有流水。旧游艺厅入口保留转接只为兼容旧版本，新模组直接使用公共接口。
